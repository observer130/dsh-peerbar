# dsh-peerbar

把多台 dsh 聚合成**一个前端**：本机 + 各远端的工作区/会话归纳在同一个官方侧栏里，执行始终在远端。走 HTTP/TLS 直连，不需要 SSH 隧道。

## 能做什么

- **统一侧栏**：本机与各远端的工作区/会话混排在**官方侧栏**里
- **按主机分组**：侧栏顶层是多个可折叠行（本机显示器、远端云图标），展开就是该主机的工作区
- **「远程主机」设置**：标题 + 每台主机一张卡（红/绿/黄状态点、「在线 / 离线 / 需要令牌」徽标、刷新 / 令牌 / 删除）+ 卡片下方的「添加」
- **状态可见**：每台 Host 在线与否、延迟多少，在设置页一栏看清；工作区信息读取失败时保留缓存标题
- **子智能体与后台任务照常**：远端会话标题栏的「N 个子智能体」带每行的标题、token 用量与耗时，点一行直接打开子会话；「N 个后台任务运行中」与任务输出面板同样可用

## 适配版本

| 项 | 要求 |
| --- | --- |
| DeepSeek Harness | 桌面 `0.2.2-alpha.3`（实测）；远端 `0.2.1-rc.2` / `rc.3`（实测） |
| 宿主形态 | DSH Desktop 与 `dsh web` |
| 远端 | 正在运行的 dsh，地址可直连（局域网即可），远端不用装本插件 |

## 安装

### 从 GitHub 安装（推荐）

1. 打开 DSH Desktop → 侧栏 **插件** → 右上 **添加插件**
2. 输入仓库地址 `https://github.com/observer130/dsh-peerbar`，点 **安装**
3. 装完点 **立即启用**（插件卡片上的开关也行）；侧栏出现「本机 / 远端主机」分组即已生效

### 从仓库目录（开发用）

1. 侧栏 **插件** → 右上 **添加插件**
2. 填本仓库的绝对路径
3. 装完点 **立即启用**

### 发布说明

仓库根就是一个可直接安装的**组合包**，安装器按 commit 打包。

## 使用

1. **设置 → 远程主机**，添加 Host：名称、地址（如 `https://10.0.0.10:3080`）、访问令牌
2. 令牌就是远端 dsh 启动时 URL 里 `?token=` 后面那串
3. 远端用自签证书时勾上「跳过证书校验」（仅内网）

## 注意事项

- **会在远端执行写操作**：发消息、停止、改名、归档/置顶、分叉、新建/删除工作区、终止后台任务（都只由你亲手点触发）。
- **不搬运文件内容**：远端会话里的文件引用只做提示，不会在本机打开同名文件；要看内容请用右侧「文件」面板（只读，直接读远端）
- **远端 localhost 链接**：从聊天区走「侧边栏打开」时会被拦下并复制地址。
- **凭据只留在本机**：令牌与换来的 cookie 存在 `~/.dsh/dsh-peerbar.json`（权限 0600），响应里不会回传明文
- **自签证书**：默认拒绝不受信任的证书。局域网自签需对该 Host 单独打开「跳过证书校验」，仅建议内网使用。
- **需要能直连**：不做中转、不做 NAT 穿透，只支持同网段或可直达的地址
