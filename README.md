# dsh-peerbar

把多台机器上的 DeepSeek Harness 聚进一个侧栏，用 Host 标签区分来源。走 HTTP/TLS 直连，不需要 SSH 隧道。

> **状态：v0.1 已在本机 DSH Desktop 跑通，尚未发布到 npm。** 目前从仓库目录安装，行为即下面所述。

## 解决什么问题

三台机器各开一个 dsh 页面，切换麻烦、容易记错在哪台执行；想在 A 机续聊 B 机开过的会话，只能去 B 机的页面里翻。

装上 dsh-peerbar 之后：

- **一眼看清**——所有 Host 的工作区排进同一个视图，每行带彩色 Host 标签，可按来源过滤、按标题搜索
- **跨机找会话**——展开远端工作区能看到它的会话：标题、最后活动时间、运行状态；点开可读正文
- **断线不崩**——某台机器离线时该组置灰，仍可展开上一次的快照；恢复后自动回色并刷新
- **不碰你的数据**——v0.1 只读，不修改远端任何内容

## 适配版本

| 项 | 要求 |
| --- | --- |
| DeepSeek Harness | `0.2.1-rc.2`（0.2.1-rc.x） |
| 宿主形态 | DSH Desktop（主力验证环境）；`dsh web` 用同一套包，未逐一验证 |
| 远端 | 正在运行的 dsh，地址可直连（局域网即可） |

## 安装

从本仓库目录安装（未发布 npm）：

1. 打开 DSH Desktop → 侧栏 **插件** → 标题旁箭头 → **安装第三方插件**
2. 填本仓库的绝对路径（如 `/home/nwj/Projects/dsh-peerbar`）
3. 装完点 **立即启用**，重启 DSH Desktop 使插件生效（改了宿主半也要重启）

## 使用

1. **设置 → 多机侧栏**，添加 Host：名称、地址（如 `https://10.0.0.10:3080`）、访问令牌
2. 令牌就是远端 dsh 启动时 URL 里 `?token=` 后面那串；只在换 cookie 时用一次，之后 30 天内不必再填
3. 远端用自签证书时勾上「跳过证书校验」（仅内网）
4. 保存后自动探活，状态显示 在线 / 需要令牌 / 连不上 / 证书不受信 / 不是 dsh / 版本不兼容
5. 侧栏出现 **多机** 图标，点开是聚合视图；点会话标题可读正文（右上角返回）

## 注意事项

- **只读**：v0.1 只能查看工作区、会话列表与会话正文，不能远程新建会话、发消息或改文件
- **凭据只留在本机**：令牌与换来的 cookie 存在 `~/.dsh/dsh-peerbar.json`（权限 0600），响应里只有 `hasToken` / `hasCookie`，不会回传明文
- **自签证书**：默认拒绝不受信任的证书。局域网自签需对该 Host 单独打开「跳过证书校验」，仅建议内网使用；更稳的做法是给系统加信任根，或用 `caFile` 指定 CA
- **需要能直连**：不做中转、不做 NAT 穿透，只支持同网段或可直达的地址
- **不需要额外端口**：远端只要跑着 dsh，不用开 SSH，也不用新开端口，远端不用装本插件
- **远端插件不会被加载**：远端只提供数据，界面全部在你本机渲染
- **工作区由目录合成**：远端 Remote 没有工作区读端点，视图里的「工作区」是按会话 `cwd` 分组的目录

## 已知限制

- **不能深链到某个会话**：远端 dsh 没有会话级 URL 路由，只能给 Host 首页
- **界面只能从本机访问**：插件的 `/dsh-peerbar/api/*` 只接受回环 + 同源请求；从别的机器用浏览器打开本机 dsh 时，聚合页会报 403
- **只显示最近 30 条**，更早的要往上一页页点
- **工具输出会截断**（单条 4000 字），完整内容请到远端看
