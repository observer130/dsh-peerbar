# dsh-peerbar

把多台机器上的 DeepSeek Harness 聚进一个侧栏，用 Host 标签区分来源。走 HTTP/TLS 直连，不需要 SSH 隧道。

> **状态：开发中，v0.1 尚未发布。** 目前没有可安装的版本，下面是 v0.1 的目标行为。

## 解决什么问题

三台机器各开一个 dsh 页面，切换麻烦、容易记错在哪台执行；想在 A 机续聊 B 机开过的会话，只能去 B 机的页面里翻。

装上 dsh-peerbar 之后：

- **一眼看清**——所有 Host 的工作区排进同一棵树，每个工作区带彩色 Host 标签
- **跨机找会话**——展开远端工作区能看到它的会话：标题、最后活动时间、运行状态
- **断线不崩**——某台机器离线时该组置灰，仍可展开上一次的快照；恢复后自动回色并刷新
- **不碰你的数据**——v0.1 只读，不修改远端任何内容

## 适配版本

| 项 | 要求 |
| --- | --- |
| DeepSeek Harness | `0.2.1-rc.2`（0.2.1-rc.x） |
| 宿主形态 | DSH Desktop（主力验证环境）；`dsh web` 用同一套包，未逐一验证 |
| 远端 | 正在运行的 dsh，地址可直连（局域网即可） |

## 安装

v0.1 未发布，暂不可安装。发布后：

1. 打开 DSH Desktop → 侧栏 **插件** → 标题旁箭头 → **安装第三方插件**
2. 填包名 `dsh-peerbar`（或本地目录的绝对路径）
3. 装完点 **立即启用**，重启 DSH Desktop 使插件生效

## 使用

1. **设置 → 多机侧栏**，添加 Host：名称、地址（如 `https://192.168.3.50:3080`）、访问令牌
2. 保存后自动探活，状态会显示 在线 / 需要令牌 / 连不上 / 不是 dsh / 版本不兼容
3. 侧栏出现 **多机** 入口，点开即是聚合视图

## 注意事项

- **只读**：v0.1 只能查看工作区与会话列表，不能远程新建会话、发消息或改文件
- **令牌只留在本机**：存在 `~/.dsh/dsh-peerbar.json`（权限 0600），不会回传给页面
- **自签证书**：默认拒绝不受信任的证书。局域网自签证书需对该 Host 单独打开「跳过证书校验」，仅建议内网使用；更稳的做法是让对方改用 HTTP 或给系统加信任根
- **需要能直连**：不做中转、不做 NAT 穿透，只支持同网段或可直达的地址
- **不需要额外端口**：远端只要跑着 dsh，不用开 SSH，也不用新开端口
- **远端插件不会被加载**：远端只提供数据，界面全部在你本机渲染
