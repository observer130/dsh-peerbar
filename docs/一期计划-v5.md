## 3. 实施约定

- **每个任务一个 commit**，commit message 带任务号，正文写根因 + 验证方式。
- 每完成一项就地跑：`env -u NODE_OPTIONS /usr/bin/node --test test/*.test.js`。
  （沙箱 `RLIMIT_AS=4GB`，托管 Node 22 一碰 fetch 就 WASM OOM，必须用系统 Node 26。）
- 改动触及宿主半（`lib/rpc.js`/`lib/index.js`/`lib/remote.js`）时，需要**重启**才能生效；
  纯客户端改动刷新窗口即可。
- 浏览器级验证用 `systemd-run --user` 起 headless Chrome + puppeteer `connect()` 绕开
  RLIMIT_AS（脚本结尾 `disconnect()`，不要 `close()`）。
- 桌面端 boot 必须真机验证（single 槽事故教训），不过本期不新增槽位注册，风险低。

### 顺带的工程改进

- `scripts/ui-check.mjs` 支持 `--cdp <url>`：连一个已在运行的 Chrome，
  绕开沙箱 `RLIMIT_AS=4GB` 不能直接 launch 的限制（脚本结尾走 `disconnect`，
  不能 `close`，否则下次连不上）
- `lib/remote.js` 抽出 `buildPageRequest` 纯函数（分页语义可单测）
- 顺手删掉 `/session` 路由里调用已不存在的 `readTranscriptFrom` 的死分支
  （原来被调用就 ReferenceError）

### 验收时请重点看

1. **长会话**：打开一条历史很长的远端会话，往上滚应该自动加载更早的，
   一路能到最开头（首屏也要比之前明显长）
2. **远端改名**：在侧栏把某个远端会话改名，聊天页窗口标题应立即跟着变
3. **T7 需人工点一次**：远端会话里如果有文件引用链接，点它应出现
   「在远端 xxx 上」的提示条，而不是打开本机文件
   （本次 e2e 的会话里没找到渲染成用户文本节点的文件引用，无法自动断言）

### 已知残留

- **主视图面包屑不跟改名**：`ui-conversation` 的 `deriveAncestry` +
  `equalBreadcrumbs` 读的是 `useSessions` 的内部选择器缓存，远端绑定拿不到
  通知；绕过需要更深的 hook patch，风险大于收益。窗口标题与侧栏行已同步。
- **T1 的 `turnWindow` 效果偏宽**：远端有时会把剩余全部返回（一次 132 事件），
  不影响正确性（只多不少），但页宽不严格。后续若要更省流量可再调。

## 6. 验收反馈修复（2026-10-26 第二轮）

| # | 反馈 | 根因 | 修法 |
| --- | --- | --- | --- |
| 2 | 改标题/归档/删工作区要等 5s 以上 | `/state` 来自探活快照，探活 5s 一轮；操作后重拉拿到的还是旧快照（RPC 本身只要 ~30ms） | `peers.applyLocalEcho` 在 RPC 成功后**就地回写快照**（归档/置顶/会话改名/工作区改名/删除），客户端只广播重拉，探活转后台 |
| 3 | 点远端文件引用仍唤起侧栏并报 `workspaceFileScope` 错 | `patchRemoteFileLinks()` 只尝试一次；`sidebarRight` 在插件加载顺序上晚于我们 → 拿到 null 就永久放弃 | 改成失败时 250ms 轮询重试（最多 15s），装上后打一行 info |

**实测**：归档端到端 2766ms → **719ms**（含 200ms 轮询粒度，RPC 段 ~30ms）；
改名 RPC 返回后立刻读 `/state` 已是新名；点文件引用只出提示条、右侧面板 tab 数
4→4 不再增加。45 单测 + ui-check 全部断言通过。

**顺带修**：后台探活请求必须带 `body`，否则请求封装不加 content-type /
`x-dsh-peerbar-action`，被 guard 判 415（ui-check 抓到的唯一一条真实报错）。
