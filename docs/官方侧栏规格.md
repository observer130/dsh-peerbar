## 1. 结构（`rows/Rows.tsx`）

### 1.1 工作区行 `ProjectRowItem`

```tsx
<div className={css.projectRow} data-row-key={`workspace:${key}`} role="treeitem" aria-expanded>
  <span className={css.slot + css.folder + (active && css.folderActive)}>
    {expanded ? <IconFolderOpenRegular/> : <IconFolderCloseRegular/>}
  </span>
  <span className={css.slot + css.chevron}>
    <IconTriangleRightFillRegular className={css.arrow + (expanded && css.arrowOpen)}/>
  </span>
  <span className={css.projectText}><span className={css.title}>{label}</span></span>
  <span className={css.rowActions}>
    <Menu items={[{id:'rename',label:重命名,icon:IconEdit},
                  {id:'delete',label:删除工作区,icon:IconTrash,danger:true}]}
          onSelect={(id)=>…} anchor={<button className={css.iconButton}><IconEllipsis/></button>}/>
    <Tooltip label={新建会话}><button className={css.iconButton}><IconNewChatOutline/></button></Tooltip>
  </span>
</div>
```

- 文件夹图标与 chevron **是两个 slot**：静止显示文件夹，hover 才显示三角箭头（CSS 切换）。
- 未分组桶（`workspaceId === undefined`）没有菜单、没有 hover card。

### 1.2 会话行 `SessionNodeItem`

```tsx
<div className={css.sessionRow + (selected && css.selected) + (archived && css.archived)} role="treeitem">
  <span className={css.slot}>
    {!archived && !blank && (showStatus ? <SessionStatusDots/> : renderSlot('sidebar.session.row.leading'))}
  </span>
  <span className={css.title} onDoubleClick={renameRequest}>{title}</span>
  {!blank && <span className={css.time}>{trailingLabel ?? relativeTime}</span>}
  {pinned && !archived && <PinnedIndicator/>}          // IconPinFillRegular size 14
  {!blank && (
    <span className={css.rowActions} onClick={stopPropagation}>
      <Menu anchor={<button className={css.iconButton}><IconEllipsis/></button>}>
        {renderSlot('sidebar.workspaces.session.menu.item', …)}
      </Menu>
      {renderSlot('sidebar.workspaces.session.row.action', …)}
    </span>
  )}
</div>
```

- 状态点用官方 `StateDot`：`state = 'ongoing' | 'idle' | 'done' | 'warning'`；
  运行中 `ongoing`，否则 `idle`（完成未读是 `done`）。
- 标题**双击**触发重命名（不只是菜单）。
- 时间用官方 `relativeTime` + i18n（`time.now` / `time.minute` 等）。
- 归档行：整行 `archived` 灰色，slot 留空。

## 2. 菜单项（`session-actions/`，order 决定顺序）

| order | id | 文案 | 图标 | 行为 |
| --- | --- | --- | --- | --- |
| 100 | pin | 置顶会话 / 取消置顶 | `IconPinOutline` / `IconPinFill` | `pinSession` / `unpinSession` |
| 200 | rename | 重命名 | `IconEditOutline` | 打开**重命名 Modal**（不是行内输入） |
| 300 | fork | 分叉会话 | `IconBranchOutline` | `forkSession` |
| 400 | archive | 归档会话 / 取消归档 | `IconArchiveOutline` / `IconUnarchiveOutline` | `archiveSession` / `unarchiveSession` |
| 450 | session-id | 复制 Session ID | `IconCopyOutline` | 写剪贴板 |

行内 hover 按钮（`sidebar.workspaces.session.row.action`）：

| order | 按钮 | 图标 |
| --- | --- | --- |
| 100 | 归档 / 取消归档 | `IconArchiveOutline` / `IconUnarchiveOutline` |
| 200 | 置顶 / 取消置顶 | `IconPinFill` |
| — | 更多（⋯） | `IconEllipsisOutline` |

→ 所以一行 hover 出来的是**三个按钮：归档、置顶、⋯**（我当前实现是「置顶、重命名、⋯」，顺序与组成都不对）。

## 4. 分组与过滤（`tree.ts` / `WorkspaceBrowser.tsx`）

- 可见性：`origin === 'subagent'` 不显示；`blank` 只显示当前选中的那个；归档默认隐藏。
- 未分组桶：`group.ungrouped`，永远排在最后。
- 溢出：`collapsed.hiddenCount > 0` 时渲染 `css.sessionOverflowButton`（「展开含 N 个会话」），不是简单截断。

## 5. 与当前实现的差异（S3 必须逐条修）

| # | 现状 | 官方 | 影响 |
| --- | --- | --- | --- |
| 1 | 只有 chevron，没有文件夹图标 | folder + chevron 双 slot，hover 切换 | 视觉不一致 |
| 2 | 状态点是自绘 6px 圆点 | 官方 `StateDot`（ongoing/idle/done/warning） | 状态语义缺失 |
| 3 | 行内按钮 = 置顶/重命名/⋯ | 归档/置顶/⋯ | 用户直接指出 |
| 4 | 重命名是行内 input | 官方 Modal 对话框 | 交互不一致 |
| 5 | 菜单用 `MenuItemButton` children | 官方 `Menu items=[…]`，带 order | 顺序/图标可能不一致 |
| 6 | 文案「改名」 | 「重命名」 | 用户直接指出 |
| 7 | 菜单无快捷键提示 | `shortcut={useShortcuts(...)}` | 少一块 |
| 8 | 头部只有搜索图标 | 搜索 + 视图选项 + 新建工作区 | 少两个按钮 |
| 9 | 依赖构建期哈希类名 | 应用源码 `*.module.css` 的规则自建同名样式 | 版本一升就碎 |

## 6. S3 的技术选择

**不再用构建期哈希类名。** 源码里每个行组件都有 `*.module.css`（如 `rows/Rows.module.css`），
MIT 可直接把其中的规则抄进插件自己的 CSS（改前缀 `dshp-`），这样：

- 视觉 100% 等于官方（同一份规则，不是仿写）；
- 不依赖构建期哈希，官方升级只要 CSS 没改就不受影响；
- 组件的 DOM 结构按本文第 1 节照抄。

S4 开始按此重写，每步用 `scripts/ui-check.mjs` 截图比对。
