## 1. 目标（一句话）

打开本机 dsh，**左边那一列本身就列出本机 + nv50 + m50 的工作区与会话**，视觉上是同一棵树；
点本机会话走原生对话，点远端会话在**原生中栏**读只读正文。

不新增图标、不新增页面、不新增标签。

## 4. 前置实验（只改客户端，刷新即可）

### E1：无侧栏图标也能选中 main 面板

1. 注册 `main` key `peerbar-session`（先渲染一行占位文字），**不注册** `sidebar.panellist`；
2. 在树里点一个远端会话行 → `setTarget(...)` + `ctx.layout.selectPanel('peerbar-session')`；
3. 观察 10s：中栏是否停住、是否被弹回 `conversation`、点本机会话能否回来。

**判定**：停住 ≥10s 且本机会话可正常打开 → 通过。
**失败退路**：R1 补一个 `sidebar.panellist`（order 放末位），功能优先；R3 用 `shell.overlay` 浮层。

### E2：本机树的数据形状

在组件里打印 `useWorkspaces((s) => s)` 与 `useSessions()` 的实际结构，确认能拿到：
工作区 `{ workspaceId, cwd, name, pinned }`、会话 `{ sessionId, title, updatedAt, running, archived? }`。

**判定**：够渲染 → 直接用 hooks（不重复拉接口）。
**退路**：恢复 `/state` 的 `local` 段（宿主侧代码在 git 历史里，约 30 行）。

## 8. 验收清单（v0.1）

1. 侧栏是一棵树：本机在前、远端在后，**没有**「本地 / 远端」两个分区标题
2. 远端组名后带短标签（nv50 / m50），颜色与设置页一致
3. 点本机会话 → 原生对话区正常打开，行为与官方一致
4. 点远端会话 → 中栏只读正文；输入区禁用并提示「只读，请在远端继续」
5. 远端断线：组置灰、可展开缓存标题、点行提示「连不上」，不白屏；恢复 ≤10s 回色
6. 折叠状态、搜索在刷新后仍可用
7. 停用插件 → 侧栏完全回到官方形态，无残留
8. 设置 → 多机侧栏：Host 增删改查、探活、令牌替换仍然可用
9. `scripts/security-check.sh` 10/10；`node --test test/*.test.js` 全绿
